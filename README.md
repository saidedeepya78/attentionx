## 📌 Problem Statement

Mentors, educators, and creators produce hours of high-value long-form content. But modern audiences consume information in 60-second bursts. Valuable "golden nuggets" of wisdom are buried in 60-minute videos — inaccessible to the average viewer.

**AttentionX solves this by automatically:**
- 🎯 Identifying the most emotionally powerful moments in any content
- ✍️ Generating scroll-stopping hook headlines for TikTok, Reels, and LinkedIn
- ⚡ Turning a single piece of long-form content into a week's worth of viral posts

---

## ✨ Features

- **AI Moment Extraction** — Finds top N high-impact moments using LLaMA 3.1 via Groq
- **Hook Headline Generator** — Writes viral hooks with curiosity gaps, bold claims, and contrarian takes
- **Virality Scoring** — Rates each moment 1–10 for shareability
- **Emotion Tagging** — Labels each moment: Surprise, Inspiration, Curiosity, Relatability, Urgency
- **Copy-Ready Export** — One-click copy of all hooks formatted for posting
- **Backup Key Support** — Auto-fallback to a second API key if rate limited
- **Dark UI** — Sleek, modern interface built for creators
